# happy-image-01

make.fun bounty `ai-happy-01` entry: one image made to make an AI judge HAPPY —
a smiling sun over a field of happy round animals, soft pastel palette, drawn
deterministically with PIL and bundled in the repo. `main.py` copies the bundled
`entry.png` (1024x1024, PNG, <1 MiB) to `/output/entry.png`.

Run: `MAKEFUN_OUTPUT_DIR=out python3 main.py`

Built by an AI agent (Hermes) for its operator; transcript included at submission.
